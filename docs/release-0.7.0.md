# CiliCiliWinRev 0.7.0

* 使用应用自己的 Material 3 更新弹窗，点击“立即更新”后才下载安装包。
* 应用内显示下载进度，支持取消和失败重试，无需跳转浏览器。
* 安装包通过 SHA256 和 Ed25519 签名校验后，保存观看进度，自动退出并安装。
* 安装时只显示进度窗口，沿用当前安装目录与账号设置；成功后删除下载的安装包并重新打开软件。
* Release 附件只提供 Windows x64 安装包。

0.6.x 用户需下载安装本版本一次，后续版本可使用新的更新流程。

不包含增量更新或自动回滚。当前安装包没有 Windows Authenticode 代码签名。
