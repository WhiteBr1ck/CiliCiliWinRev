## 验证边界

向真实 /pc/users/captcha 发送了兼容加密 POST，返回 HTTP 200、code 20000、uuid 和 image_base64。注册规则探测使用保留域 example.com 与从未发送的无效验证码，不会创建账号：jskdfjkf 返回 code 400101“昵称不能为非法字符”；Test1234 返回 code 40002“不能出现数字”；中文昵称进入重名校验。未创建测试账号、未发送验证码邮件、评论或弹幕。密码登录、验证码登录、注册成功、账号历史同步、评论写入及弹幕发送使用模拟接口验证；没有用户凭据，因此真实账号成功结果待用户验证。

纠正前版弹幕结论：/pc/danmu 的前一分钟样本含 59 条真实的 0，下一分钟为空；扩大到 0 至 2000 秒后返回 112 条，时间范围 0 至 1962，包含 128、298、383、469 秒等真实非零时间。原版读取 time_point，并在发送时使用 parseInt(video.currentTime)。前一分钟结果不能代表整集。0.3.0 按真实视频时长加载整集，不将无效时间默认为 0，也不伪造时间。

季度原始目录通过 Bangumi search 按首播日期获取并加载所有分页，当前季度加入公开日历中的续播作品。0.5.0 的界面只保留能可靠对应 CLICLI 且详情已有集数的作品，未定排期仍保留；存在集数也不保证每个播放源始终可用。名称、别名或年份无法确定时不会放宽匹配，可能遗漏存在但采用其他名称的作品。星期与时间未提供时不推测。

字体使用内置矢量轮廓与真实字重，保留 DPI 缩放。Flutter 使用自己的抗锯齿栅格化；本版本没有开启 Windows ClearType 的虚假声明，也未在每种显示器和缩放比例上测量视觉效果。
