# 账号同步核对，0.7.2

依据用户提供的原版 1.1.5 客户端实际代码核对，没有推测接口或使用日常账号写入测试。

| 数据 | 原版协议 | 新版处理 |
| :--- | :--- | :--- |
| 收藏 | GET /pc/collect，分页 items/total；POST /pc/collect，{vid}；DELETE /pc/collect，{vid} | 此版本补齐读取、添加及删除。登录和恢复会话后加载全部分页，进入收藏页和刷新按钮再次获取服务器数据。失败保留上一次完整列表，账号切换丢弃旧请求和旧列表。 |
| 追番 | 原版“同步收藏追剧”使用同一份收藏接口，没有独立追番接口 | 新版独立的追番列表保存在本地，不伪造服务端同步。 |
| 观看历史 | GET、POST、DELETE /pc/history | 已接入。刷新账号历史前补传待同步进度，删除时等待在途写入并清理该影片的待上传记录。 |
| 账号续播 | GET /pc/video/detail 的 history.player、history.part、history.time_point | 此版本补齐。普通详情页面可以直接继续账号中的集数和时间，仍可从本地历史显式继续观看。 |
| 账号资料及权限 | GET /pc/users/info，id、user_name、pic_url、vips 等 | 登录和恢复时已经读取。避免旧会话响应更新新会话的资料与权限。新版当前只展示已使用的字段，没有资料编辑页面。 |
| 评论、点赞 | /pc/vod_comment 的 getlist、getsublist、create、likes | 已接入服务端读写，按页面加载，无需导入本地库。 |
| 弹幕 | GET、POST /pc/danmu，time_point 与内容样式 | 已接入服务端读写；显示透明度、区域、字号属于本机设置。 |
| 消息箱、回复通知、会员订单记录 | /pc/messagebox、/pc/users/vip_records 等 | 原版支持，新版尚无相应页面，属于未实现的功能，不宣称已同步。 |
| 主题、强调色、音量、播放器及弹幕显示设置 | 没有找到对应云端设置接口 | 保存在本机。 |

本地收藏不会因登录而覆盖，也不会自动批量上传。账号收藏在账号列表内读写，详情的收藏操作遵循收藏页选择的本地或账号范围，默认使用已登录账号。退出登录后不会继续显示该账号收藏。

0.7.3 起，进入收藏和观看历史页面时，已登录默认选择账号列表，未登录默认选择本地列表。页面内可手动切换；再次进入以及登录、退出或账号切换后重新按当前登录状态选择。

观看进度队列使用 SHA256 哈希的已验证账号 ID 分区，可跨 token 更新恢复。未拿到账号 ID 时使用 token 哈希，避免猜测所有权。升级前已有的 token 队列仅在恢复相同 token 并验证账号 ID 后迁移；无法确认归属的旧队列保持隔离，不合并到其他账号。

队列写入按顺序等待 API 自身的超时，不使用会让 HTTP 写入仍在后台继续执行的额外短超时。软件退出只等待本地持久化，保留原生快速退出流程。

协议测试独立解密 POST/DELETE 请求并核对字段。模拟账号测试覆盖分页、恢复、切换、失效、写入失败重试、历史删除时序、稳定账号 ID 和详情续播；未读取日常会话文件，也未修改真实账号收藏或历史。
