# CiliCiliWinRev

基于 Flutter Material 3 重新实现的 CLICLI Windows 客户端，接入真实片库，使用 libmpv 播放视频。默认深色主题，支持浅色与跟随系统。

## 安装与运行

从 [GitHub Releases](https://github.com/WhiteBr1ck/CiliCiliWinRev/releases/latest) 下载最新的 Windows x64 安装包或便携包。

运行 `dist/CiliCiliWinRev-0.6.0-windows-x64-setup.exe` 即可安装。默认安装到当前用户的 `%LOCALAPPDATA%/Programs/CiliCiliWinRev`，无需管理员权限，支持开始菜单快捷方式、可选桌面快捷方式及卸载。后续安装包会覆盖升级到同一目录，账号会话和本地偏好保留。

在源码目录中打开 `dist/CiliCiliWinRev-0.6.0-windows-x64/CiliCiliWinRev.exe`。

也可以把 `dist/CiliCiliWinRev-0.6.0-windows-x64.zip` 解压到任意目录，再运行其中的 `CiliCiliWinRev.exe`。整个目录中的 DLL 和 data 文件夹都需要保留。

如果你已经打开解压后的便携包，直接双击与本文件在同一目录的 `CiliCiliWinRev.exe`。包内包含播放器及所需的 Visual C++ 运行库。

提供 Windows x64 安装版和便携版，均不需要原版客户端。支持 Windows 10 或 Windows 11。

## 已实现

* 首页推荐大图、人气精选与最近上架，内容来自实时片库。
* 分类、关键词搜索、类型、年份和地区筛选、排序与分页。
* 作品详情、简介、播放源与选集。长篇作品按 50 集分组，并支持查找集数。
* 内置视频播放、HLS 与 H.265 解码、暂停、拖动进度、长音量条、静音、倍速、可用画质切换、手动和自动播放下一集。普通窗口静止三秒、全屏静止两秒隐藏控件和鼠标。紧凑弹幕输入位于工具栏中部，窄窗口移到工具栏下一行，右侧选集为三列。
* 整集弹幕时间轴、显示开关、播放器内发送弹幕。支持颜色、滚动/顶部/底部、小号/标准，以及透明度、字号与显示区域设置。
* 密码登录、邮箱验证码登录、邮箱注册、图片算式验证码、会话恢复与退出登录。
* 本地与账号两种观看历史，按日期分组并显示观看时刻和进度条，登录后定期保存账号进度。账号记录缺少总时长时，复用对应集数的本地时长，或后台读取 HLS 播放列表补齐。
* 播放页评论、分页、回复、点赞与发表评论。
* 新番时间表，桌面宽度为三列，按年份、冬春夏秋季度、类型与周几浏览完整公开季度作品，包含当季续播。Bangumi 提供季度信息，AniList 补充播出时间并转换为本机时区，卡片标注 UTC 偏移。点击时才搜索 CLICLI，匹配到有集数的作品后打开详情；未收录时只显示“CliCli没有该影片”。
* 继续观看、本地收藏与追番。收藏卡片使用爱心，追番卡片使用书签。
* 普通窗口固定 16:9 视频框，原生全屏覆盖显示器，退出恢复原窗口状态；窗口置顶、拖动、最小化、最大化与缩放。
* 启动时自动检查 GitHub Releases，设置中可关闭或手动检查；有新版时提供发行说明和安装包下载。
* 深色、浅色、跟随系统，紫罗兰/蓝色/青绿/玫瑰/琥珀强调色，以及播放偏好持久化。
* 内置 Noto Sans SC 矢量字体与 400/600/700 真实字重，保留 Windows DPI 缩放。
* 本地视频文件播放。
* 封面缓存与重试。原站图片不可用或为空时，按名称、季度与年份匹配公开 Bangumi 封面；已核对死神 BLEACH、进击的巨人第四季和咒术回战第二季的名称差异。无法确定对应作品时保留可点击重试的图标。

## 当前范围

收藏和追番保存在本地。观看历史分为本地和账号，本地记录不依赖登录；账号记录来自原站接口。日期和观看时刻按服务端实际时间显示，未提供时间的记录归入“时间未知”，不以当前时间代替。登录后每 10 秒、切集、返回和关闭时保存观看进度。会话令牌使用 Windows DPAPI 加密后保存，密码不落盘。改名后首次启动会迁移 0.1.0 版本的本地偏好文件。

账号历史的进度以实际播放位置除以该集总时长计算。时长缓存按作品、播放源和集数独立保存；后台补齐只读取有限大小的 HLS 播放列表，不播放视频、不下载视频分片、不改写账号观看进度。非 HLS、直播或解析失败且无本地时长的旧记录会显示空进度轨道，悬停说明尚未取得总时长。

注册昵称遵循实测服务端规则，使用 1 至 12 个汉字，不含字母、数字或符号。纯英文昵称的“非法字符”和含数字的“不能出现数字”来自原站校验。

弹幕按服务器时间显示，无效时间会被丢弃，同一时刻超过轨道容量的弹幕不会堆叠上屏。0.3.0 在获得视频时长后，按十分钟区间读取整集弹幕。此前的前一分钟样本全部为 0，但整集样本含 128、298、383 秒等非零时间，不能把前一分钟的结果当成整集。服务器真实标为 0 的记录仍保留，发送使用当时的视频时间。下载与离线缓存尚未实现。

时间表从公开 Bangumi API 按季度完整分页获取，默认显示 TV/WEB，也可查看全部类型。当前季度追加公开日历中的续播作品，不预先核对整个 CLICLI 片库。公开 AniList 时间戳换算为本机时区与实际星期，午夜后的播出归入下一日。卡片注明 UTC 偏移，悬停时刻可查看来源和播出日期；缺失时刻显示 --:--，未定排期仍保留。只有点击作品后才使用名称、别名、季数和首播年份查找 CLICLI，并检查详情是否有集数。未匹配到可用作品时只显示“CliCli没有该影片”；网络错误独立显示且允许重试。按需查询限速并缓存十五分钟，首次加载季度不再读取各年份的整个片库。

更新来源固定为公开仓库 `WhiteBr1ck/CiliCiliWinRev` 的最新稳定 Release。每次启动检查一次，可在设置中关闭，手动检查仍可用。按数字版本比较，忽略草稿和预发行版；发现新版后在浏览器下载匹配版本的 x64 安装包，由用户运行安装完成升级。检查使用独立 HTTP 客户端，不发送 CLICLI 令牌。仓库还没有发行版时显示“暂无已发布版本”，而非“已是最新版本”。发布规范见 [updates.md](docs/updates.md)。

Flutter 使用自己的文字栅格化与灰度抗锯齿。内置字体改善字形与回退一致性，没有虚构 Windows ClearType 开关。

播放器支持当前已验证的高速云解析模板、直接视频地址与原版 mao 鉴权流程。未知解析脚本会显示可恢复的错误。需要账号权限的源依据服务器返回的频道会员状态筛选，实际播放仍由原站鉴权决定。

片库和视频由外部服务提供，服务地址及解析规则改变后，可能需要更新 `lib/services/clicli_api.dart` 和协议配置。

## 开发与构建

需要 Flutter 3.32.7 或更新的兼容版本，以及包含“使用 C++ 的桌面开发”的 Visual Studio。

```powershell
flutter pub get
flutter run -d windows
flutter analyze
flutter test
flutter test integration_test/windows_smoke_test.dart -d windows
```

构建便携版及安装包：

```powershell
./tools/build_windows.ps1 -FlutterSdk D:/1Sync/Dev/flutter
./tools/build_installer.ps1 -Compiler "C:/Program Files/Inno Setup 7/ISCC.exe"
```

安装包编译器使用 Inno Setup 7，支持中文安装界面。

本目录中的原版客户端和安装包只是分析参考，不参与编译，也没有复制到便携包中。

## 工程结构

* `lib/theme.dart`：Material 3 颜色角色、控件与主题。
* `lib/ui/`：首页、分类、片库、账号表单、历史、时间表、评论、设置与播放器。
* `lib/services/account_session.dart` 与 `session_store.dart`：账号会话与 Windows DPAPI 存储。
* `lib/services/clicli_api.dart`：服务器发现、加密协议、片库和视频解析。
* `lib/services/cover_cache.dart`：封面加载、精确匹配与缓存。
* `lib/app_state.dart`：本地偏好、收藏、追番和播放历史。
* `test/`：协议、持久化、封面匹配和界面测试。
* `integration_test/`：Windows 真实服务与播放器测试。
* `docs/screenshots/`：端到端测试生成的实际界面截图。

0.6.0 的验证包括完整季度不调用 CLICLI 片库、按需匹配与缺失提示、更新版本比较、空仓库和限流状态、启动更新提示及设置开关，并保留真实 Windows 片库与 mpv 播放验证。安装包另行核对首次安装、覆盖升级和卸载。所有账号界面测试使用内存会话，不恢复日常账号。详细结果见 [verification.md](docs/verification.md)。

协议说明见 [architecture.md](docs/architecture.md)，第三方组件说明见 [THIRD_PARTY_NOTICES.md](docs/THIRD_PARTY_NOTICES.md)。
